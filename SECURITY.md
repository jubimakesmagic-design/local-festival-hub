# Security Policy

Local Festival Hub is an MVP, but security reports are still welcome and taken seriously.

## Supported Versions

The `master` branch is the active development branch. Security fixes will be applied there first.

## Reporting a Vulnerability

Please do not disclose vulnerabilities through public GitHub issues.

Instead, contact the maintainer through the GitHub profile for `jubimakesmagic-design` and include:

- A short description of the issue
- Steps to reproduce
- The affected route, API action, or component
- Potential impact
- Any suggested fix, if available

## Sensitive Data

Do not include real personal data, private API keys, credentials, production database exports, or non-public government/internal data in issues, pull requests, screenshots, or sample files.

## Maintainer Response

The maintainer will review valid security reports, prioritize fixes based on severity, and credit reporters when appropriate and requested.
